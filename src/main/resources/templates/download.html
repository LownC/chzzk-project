데스크톱 클라이언트 다운로드

치지직 방송 목록을 보고 녹화 방송을 재생하는 Windows·macOS 앱입니다. 라이브 방송 시청은 웹 화면에서 합니다. 앱에 Java 실행 환경이 들어 있어 Java를 따로 설치하지 않아도 됩니다.

운영체제 지원 아키텍처 파일 설치·실행 방법
Windows 10·11 x64 chzzk-client-windows-x64.zip 아직 게시되지 않음
  1. ZIP 파일을 내려받아 원하는 폴더에 압축을 풉니다(설치 과정 없음).
  2. chzzk-client\chzzk-client.exe를 실행합니다.
  3. 서명하지 않은 앱이라 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.
macOS 13 이상 Apple Silicon(arm64) chzzk-client-macos-arm64.dmg 아직 게시되지 않음
  1. DMG 파일을 열고 chzzk-client를 응용 프로그램 폴더로 끌어 놓습니다.
  2. 서명·공증하지 않은 앱이라 처음 실행할 때 차단됩니다. Finder에서 앱을 Control-클릭 → 열기를 누르거나, 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 누릅니다.

참고

  • Intel Mac(x64)과 Windows on ARM용 패키지는 제공하지 않습니다.
  • 앱은 기본으로 이 서비스(https://chzzk.lowndev.com)에 접속합니다. 다른 서버를 쓰려면 --server=주소 인자나 CHZZK_SERVER_URL 환경변수로 지정합니다.
  • 앱은 코드 서명을 하지 않았습니다. 위 경고는 서명되지 않은 앱에 운영체제가 보이는 안내입니다.
